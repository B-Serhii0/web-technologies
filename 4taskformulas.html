Хімічні та математичні формули

  1. CH4 + 2O2 → CO2 + 2H2O — Реакція горіння метану
  2. E = mc2 — Формула еквівалентності маси та енергії Ейнштейна
  3. a2 + b2 = c2 — Теорема Піфагора
  4. H2SO4 — Сульфатна (сірчана) кислота
  5. (a + b)2 = a2 + 2ab + b2 — Квадрат суми двох виразів
  6. H2O — Молекула води
